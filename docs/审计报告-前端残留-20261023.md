# 前端残留与页面说明审计（2026-10-23）

> **后续更新（2026-10-23）**：F-1 已由 `docs/回收站设计方案-20261023.md` 接手，回收站已实现；
> 本报告保持当时的审计快照，F-1 的「改文案」建议不再执行。

> 范围：`src/modules/**` 的页面/抽屉/弹层、`src/app/*`、`src/design-system/*` 的可见交互与文案；
> 对照 `docs/PROGRESS.md`、451 条 Git 历史、`pb_setup/collections.json` 与设置键消费点。
> 方式：只读静态审计（未改代码、未跑构建）。判据是「控件有无真实消费者 / 文案承诺有无实现 / 改版后旧语义是否清干净」。

## 结论摘要

1. **前端确实还留着一批「看起来能用、实际没接线」的界面**：通知设置 8 个开关里 7 个、端侧加密、同步频率、工作区切换、4 项通用偏好、仪表盘「记一笔」、命令面板 3 个快捷键。
2. **一处高风险误导**：笔记删除弹窗写「删除后可在回收站恢复」，但全仓没有回收站页面、路由或恢复入口。
3. **页面上的开发辅助说明仍不少**：`Phase 7`、`Phase 6`、`listShortcuts`、`幂等`、`口径`、`软删除墓碑`、`LWW`、`docs/部署指南.md`、`**直接不出现**`（Markdown 星号直接显示）等。
4. 历史删除项（`healthScore`、`tier`、`Interaction.type`、`doing` 状态、画布档位色卡、`hideInGraph`）**已清理干净**，没有发现复活。

以下都是曾经改过数据模型/界面、本次专门反查过的项，**没有发现前端残留**：

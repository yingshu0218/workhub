# 个人 Agent 接入与笔记保存验收

拥有者可以在「设置 → Agent 接入」给一个设备或 Agent 命名，并生成十分钟内有效的一次性配对码。目标端兑换后保存独立 token，VPS 保存其散列。管理员撤销一项接入后，该凭据的下一次 HTTP、WebSocket 或 stdio 请求即被拒绝，其他接入可以继续使用。[接入步骤](一键接入-Agent说明.md)

后台的“已兑换”表示 VPS 已签发凭据。若连接端丢失响应或凭据写盘失败，可在后台找到该项，撤销后重新配对。若凭据已保存，只有客户端配置写入失败，可按凭据编号重跑配置。通用 HTTP MCP 客户端可以直接调用兑换接口。本仓库提供的安装器可为同一电脑上的 Codex 和 Hermes 分别保存凭据。

| 核验范围 | 实际结果 |
|---|---|
| 后台与设备 | 独立验收的 23 个场景全部通过。Ego 覆盖桌面及 390 像素宽的设置页、生成配对码、查看接入记录、逐个撤销和改密。两个真实安装器配置在同一临时用户目录独立连接。另一个客户端直接通过 HTTP 兑换。|
| 单次兑换与恢复 | 并发兑换同一码只签发一次。等待数据库写锁期间过期的码被拒绝。重启 Node、Relay 和 PocketBase 后，有效码沿用原到期时间，已用码再次兑换被拒绝。旧库升级、超过 100 条记录的分页、取消待配对和世代变化均已验证。|
| 身份与能力 | 关闭网页、重启客户端、修改拥有者密码后，已配对的 Agent 继续工作。撤销 A 后，新的 HTTP 请求和既有的 WebSocket、stdio 会话均拒绝 A，B 保持可用。只授予事项读取的凭据可以查事项，读取流水和写待办均失败，数据库没有新增待办。|
| 撤回预览 | 拥有者、Agent A、Agent B 的预览只能由原客户端撤回。撤回与提交并发时只有一个操作生效，界面显示的可撤回状态与服务端一致。|
| 笔记 | 在两个浏览器缓存与 500 毫秒延迟下，连续编辑保留最后输入。原保存成功、响应丢失后，只改标题仍保留正文。用户丢弃的后续草稿没有再次写入，下一次主动编辑正常保存。其他客户端推进版本时，旧页面保留本端草稿并提示冲突，人工合并只产生一次成功保存。|

最终 45 个源码和测试文件的组合通过图标检查、TypeScript、ESLint、Web 与服务端构建。Vitest 通过 **1286 项**、跳过 7 项。ESLint 有一处 `AgentAccessPanel` 初次加载 Effect 的依赖提示。真实 PocketBase 0.40.2 回归通过 **65 组**，包括可靠性 10、迁移 2、个人业务 18、同步与附件 9、独立客户端 6、退役功能 5、预览撤回 6、改密后 Agent 接入 9。

配对的 23 个场景先在 44 文件组合中独立验证。最后修正了一个已登录非拥有者被误报为 401 的问题。独立复验的 12 条身份用例区分了有效非拥有者的 403、无效凭据的 401，以及合法 Agent 可访问的状态接口。上述 65 组在加入这项修正的最终组合上通过。

能力受限的 Agent 目前仍能在工具清单中看到超出授权的工具名称，服务端执行时会拒绝越权请求。直接兑换入口已验证同一来源的限流，第二个来源 IP 的独立配额尚未实测。窄屏结果来自 Ego 模拟视口。

## 开发测试站

11 月 18 日，Ego 从管理员页面为一个只读设备生成配对码。第二个浏览器标签页兑换后，通过独立凭据读取了待办。重复兑换返回 401。在后台撤销后，同一凭据的下一次请求也返回 401。后台保留一条已撤销的测试接入记录，原有业务行均通过了指纹核对。[测试站发布记录](开发测试环境说明.md#11-18-个人-agent-配对及笔记修复)

## Mac 上的测试环境和清理

桌面壳打包网页资源，运行时通过配置的地址连接 VPS。真实协议回归在 Mac 的临时目录中使用了已有的 PocketBase 0.40.2 和合成数据库。本轮没有安装系统服务、Homebrew 包或新的运行时依赖。

盘点找到三份相同的 PocketBase 可执行文件，每份 31,833,474 字节。它们位于 11 月 13 日的测试工具目录、浏览器测试副本和后续复制的工作区，现已全部删除。原始下载来源无法从保留记录确认。清理时也停止了配对测试进程和仍打开 11 月 13 日合成库的旧服务。

清理覆盖合成数据库、复制的 Rust 构建目录、测试工作区和已上传的本机发布包。删除前的分配块合计 **2,245,943,296 字节（2.09 GiB）**，文件逻辑大小合计 2,146,463,634 字节。清理后再次用 `ps` 和 `lsof` 核对，相关进程、监听和文件句柄均为零。本轮 Ego 验收使用的专用回环地址也已清空本地存储和 IndexedDB，两个测试标签及 SSH 转发均已关闭。保留了轻量验收记录、旧截图及用户原有的工作差异备份。

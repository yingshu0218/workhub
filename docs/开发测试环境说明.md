## 2. 真实链路（与早期文档不一致处，以此为准）

```
浏览器 https://dev.fpigeon.fun:443
  └─ anime-nginx 容器（宿主机 80/443，复用通配符证书 *.fpigeon.fun）
       └─ 反代 172.18.0.1:9001
            └─ 宿主 nginx（/etc/nginx/conf.d/nexus.conf）
                 ├─ /            → /opt/pocketbase/pb_public   （前端静态发布物）
                 ├─ /relay       → 127.0.0.1:9100              （nexus-relay.service）
                 └─ /api/ · /_/  → 127.0.0.1:9002              （PocketBase 0.40.2）
```

**两处与早期文档不符，务必按此表理解**：

| 早期文档写法 | 实际 |
|---|---|
| 「PocketBase 监听 `0.0.0.0:9001`」 | PocketBase 在 **`127.0.0.1:9002`**；**9001 是宿主 nginx**（托管前端静态 + 反代） |
| 「访问地址 `http://8.153.19.221:9001`」 | 入口是 **`https://dev.fpigeon.fun`**（HTTPS 已于 2026-09-12 接入） |

### 服务端常驻单元

| 单元 | 作用 | 监听 |
|---|---|---|
| `pocketbase.service` | PocketBase 0.40.2（同步 API + 数据真源 + pb_hooks） | `127.0.0.1:9002` |

## 4. 环境边界（测试期约定）

1. **数据可丢** —— 允许随时清库、重置、导错数据。不要在这里模拟真实客户。
2. **多人共用** —— `demo` / `user1` 是多端共用的同一份团队数据；测试时请注意别人的数据别被自己的用例覆盖。
3. **同步是同一账号的语义** —— 两端要用**同一个账号**才会互相同步（本期语义：2 名成员 × 多端登录共享一份团队数据）。
4. **桥要人工启用** —— 每次新开浏览器 profile 都要「设置 → AI Agent 桥 → 启用」，否则 `tools/list` 报 `-32001`（这不是配置错误）。
5. **多设备端** —— 多设备的真实场景需要外部可达的站点地址，当前测试环境已满足（HTTPS + 域名）。

## 5. 部署

见 `docs/部署指南.md`。当前环境用 `scripts/deploy.mjs` 一键部署：

```bash
# 仓库外先准备好 .deploy.env（见 .deploy.env.example）
node scripts/deploy.mjs --light    # 仅更新前端 + hooks（Schema 未变）
node scripts/deploy.mjs --full     # 还需导入 collections（Schema 有变，需超管凭据）
```

**跑部署必须前台执行**（后台任务不享受沙箱豁免，读不到 `~/.ssh/config`，`devtest` 别名会解析失败）。

## 验证与证据

本机日志目录：`/private/tmp/workhub-reliability/`。远端主回归日志为根目录 `integration.log`，迁移回归为 `migration.log`；各日志打印其独立临时数据库与 PB 日志目录。日志不包含账号密码或 token。

- `npm run check:all`：图标、TypeScript、eslint、Vitest `--maxWorkers=4`。
- `npm run build`、`npm run build:server`：分别覆盖生产 Web 与 Node/PB 共享核心构建。
- `PB_BIN=<指定0.40.2二进制> npm run test:integration`：只在新临时库运行，禁止改接正式数据。
- `WORKHUB_SMOKE_ENV=<本实例受保护环境文件> node scripts/integration/deployment-smoke.mjs`：真实生产入口 HTML 哈希、无浏览器 MCP、具体预览、票据上下文、消费后重试、金额回读和旧协议封锁。

真实旧库夹具固定为 04218ca schema 和合成 owner/ledger/transaction，验证增量迁移、重跑幂等、精度异常整轮回滚和升级前备份的隔离恢复。无真实客户或生产凭据参与。

## 备份和恢复

见 [可靠提交协议](可靠提交协议-20261111.md)。运行中使用 PB 原生在线备份；冷备份先停止本项目单元，再执行 `PB_DIR=<本实例data父目录> BACKUP_DIR=<本实例backups> PB_STOPPED=1 bash pb_setup/backup.sh`。不把热拷贝主库和附件当作可恢复备份。

恢复必须指向空目录、开启隔离，校验完成后轮换世代。RESTORE_REVIEW_REQUIRED 未核对前 entrypoint 拒绝启动；恢复点后的操作及外部删除登记缺失时不得直接开放。旧客户端、旧票据与未提交请求不能绑定新世代继续写入。

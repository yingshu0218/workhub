## 14. 交互动效（明细见 `design/DESIGN.md` Motion 章节）
- 分层：`index.css` 的 `--motion-*` + `@theme --ease-*` → 语义类（`.anim-*` / `.press` / `.press-flat` / `.lift` / `.anim-fill` / `.app-nav-link` / `.app-tab-pill` / `.anim-fade`）→ `usePresence.ts`（弹层出场）· `useRowExit.ts`（**列表行**退场）· `stagger.ts`（错峰）。**零动画库依赖**
- ⚠️⚠️ **入场类必须 `backwards`、出场类必须 `both`**。CSS 动画声明优先级**高于** `:hover`/`:active` → 入场类若用 `both`，播完后仍持有 `transform`，**同元素上的 hover 抬升 / `.press:active` 全部静默失效**
- ⚠️ **只动 `transform`/`opacity`**。豁免仅两处且署名：`.anim-fill` 的 `width`、`nx-row-out` 的 `max-height/padding/margin`。锁为**白名单式**。⚠️ 判定必须**逐条解析属性名**（子串法必误报：`max-height:` 含 `height:`）
- ⚠️ **时长一律 `calc(基时 * var(--motion-duration-scale))`**，倍率默认**引用 `var(--skin-motion-scale)`**（写死 1 会让四套皮肤的倍率被无声无视）
- ⚠️⚠️ **退场行必须「留在原位」，绝不能追加到数组末尾**（用户实测「点击完成待办没看到任何交互」）：追加到末尾 → 退场行**瞬移到列表底部**淡出、原位置下方行**立刻上移一格** = 「行突然不见 + 列表跳动」。实现：`leaving` 项记原索引 `at`、按 `at` 稳定插回。⚠️ **本笔记此前这条写反了**，已纠正
- ⚠️ **行退场必须「淡出 + 高度收拢」同时做**：只淡出是「行先变淡 → 位置被突兀填上」，**比不做更刺眼**。`useRowExit.ts` 与 `nx-row-out` 的 `max-height` **缺一不可**
- ⚠️ **`useRowExit` 的 `duration` 默认 0 = 立即移除**：jsdom 不跑样式引擎/不派发 animationend
- ⚠️⚠️ **退场行必须彻底不可交互**（实测真 bug）：退场行数据是 `useRowExit` 的**快照**（抓于该行被移出 filtered 之前）→ 打勾后其快照 `status` 仍是 `'todo'` → 点按钮走错分支 → **拿陈旧数据覆盖当前记录**。两防线：行根 `pointer-events-none`（真浏览器主防线）+ 各写库按钮 `disabled={leaving}`（jsdom 不跑 CSS，需 JS 兜底）
- ⚠️ **列表判空要用「含退场行」的数组**（`rows.length`）而非 `filtered.length`：否则**打勾最后一条**时走空态分支 → **列表容器连同 `useRowExit` 整树卸载**。⚠️ 但**计数**仍用 `filtered.length`
- ⚠️⚠️ **悬停底色必须用 `surface-hover-*` 专用档，不能用 `surface-container-*`**。原因：后者同时承担**静态卡片底色 84 处**（比悬停 37 处还多）→ 加深它会整体压暗界面，不加深则悬停看不见（亮色 Δ19、**暗色仅 Δ10**）。亮色 `#dce9ff/#cfe0ff/#bed5ff`、暗色 `#223050/#2a3c63/#34496f`。**判据 = RGB 欧氏距离 Δ ≥ 40**（锁 `styles/__tests__/hoverPalette.test.ts`）。加深后**不要再叠低透明度**
- ⚠️ **选色要量化**：用「与底色的 RGB 欧氏距离 Δ」+「文字对比度（WCAG AA ≥ 4.5）」。**用户说「不够明显」时先把现状 Δ 算出来**
- ⚠️ **`.surface-card-*` / `.press` / `.lift` / `.anim-*` 都是无层级声明**（优先级高于 `@layer utilities`）→ **无层级规则会「整条覆盖」layer 内同类属性声明**。① 给导航项加动效**写 CSS 即可自动压掉 Tailwind `transition-all`、组件零改动**；② ⚠️ **但 `.press` 的 `transition` 必须自己把颜色属性也列进去** —— 否则它会把 `transition-colors` **整条压掉**，`hover` 变色退化为**瞬间跳变**（修 `2f341d3`）。**写法照 `.lift`**；③ 判断这类冲突**要看编译产物**
- ⚠️ **给 SVG 节点挂动画只能用 `anim-fade`（纯 opacity）**：SVG `transform` 是**呈现属性**，CSS 动画会覆盖坐标 → 节点集体飘到原点。`useForceGraph` 依赖**零改动**（`CrmCanvasPage.mode` 也因此不接动效）
- ⚠️ **路由 wrapper 必须 `min-h-full`**（`InspirationPage` 用 `h-[calc(100%+3rem)]` 依赖父级确定高度）；**不能**加 `overflow-hidden`（切断 main 滚动）
- ⚠️ **`data-motion` 没有 `full` 选择器**（CSS 只有 `reduced`/`off`）→ 选「全效」须 `delete root.dataset.motion`；`prefers-reduced-motion` 独立且优先级更高。`isMotionOff()` 从 `usePresence` 导出复用——**降级判定只能一处实现**
- ⚠️ **不是所有列表都接错峰**：控件（左栏清单、筛选 chip 行、配置导航）**不接**，只接「内容列表」
- 弹层出场靠 `usePresence`（关闭时保持挂载、`animationend` 或定时器先到者卸载）；⚠️ **以定时器为主**——jsdom 不派发 `animationend`
- ⚠️ **改动常驻挂载的组件要清点其内部依赖上下文的 hook**（`EntityHoverCard` 常驻后 `useNavigate` 在无 Router 测试里直接抛错）

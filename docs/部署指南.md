## 1. 上传并安装 PocketBase

```bash
# 本地：上传物料
scp dist/ server:/var/www/nexus/            # 前端静态文件（-r，或先 tar）
scp -r pb_setup/ server:/opt/nexus/pb_setup

# 服务器上
PB_VERSION=0.28.0    # 执行前到 GitHub Releases 核对最新版本，要求 >= 0.23
cd /opt/nexus
wget https://github.com/pocketbase/pocketbase/releases/download/v${PB_VERSION}/pocketbase_${PB_VERSION}_linux_amd64.zip
unzip pocketbase_${PB_VERSION}_linux_amd64.zip -d pocketbase
cp -r pb_setup/pb_hooks pocketbase/
cp pb_setup/backup.sh pocketbase/ && chmod +x pocketbase/backup.sh
cd pocketbase
./pocketbase superuser create admin@example.com <管理员密码>
```

## 2. systemd 常驻

```bash
sudo tee /etc/systemd/system/pocketbase.service <<'EOF'
[Unit]
Description=PocketBase (Nexus Workspace sync)
After=network.target

[Service]
Type=simple
User=pocketbase
WorkingDirectory=/opt/nexus/pocketbase
ExecStart=/opt/nexus/pocketbase/pocketbase serve --http=127.0.0.1:8090
Restart=always
RestartSec=5

[Install]
WantedBy=multi-user.target
EOF

sudo useradd -r -s /usr/sbin/nologin pocketbase || true
sudo chown -R pocketbase:pocketbase /opt/nexus/pocketbase
sudo systemctl daemon-reload
sudo systemctl enable --now pocketbase
sudo systemctl status pocketbase   # active (running) 即可
```

导入 collections 并创建同步账号（见 `pb_setup/README.md` 第 2/3 节）：管理后台 `http://<IP>:8090/_/`（导入完成后建议在防火墙或 Nginx 层限制 `/_/` 与 `/api/` 之外的路径暴露）。

## 3. Nginx 反代：前端静态 + API 同域

```nginx
# /etc/nginx/sites-available/nexus
server {
    listen 80;
    server_name sync.example.com;          # 换成你的域名
    client_max_body_size 25m;              # 附件上传（pb 单文件上限 20MB）

    root /var/www/nexus;                   # dist/ 上传位置

    # 前端 SPA
    location / {
        try_files $uri $uri/ /index.html;
    }

    # /assets/ 静态资源长缓存（Vite 指纹文件名）
    location /assets/ {
        expires 30d;
        add_header Cache-Control "public, immutable";
    }

    # PocketBase API 同域反代（前端设置页只需填 https://sync.example.com）
    location /api/ {
        proxy_pass http://127.0.0.1:8090;
        proxy_http_version 1.1;
        proxy_set_header Host $host;
        proxy_set_header X-Real-IP $remote_addr;
        proxy_set_header X-Forwarded-For $proxy_add_x_forwarded_for;
        proxy_set_header X-Forwarded-Proto $scheme;
    }

    # PocketBase 文件直链（附件还原走 /api/files/，已包含在 /api/ 内，无需单独配置）

    # 管理后台：仅放行你的常用出口 IP（可选但强烈建议）
    # location /_/ {
    #     allow <你的IP>;
    #     deny all;
    #     proxy_pass http://127.0.0.1:8090;
    # }
}

# 管理后台与 /api/ 同理都在 8090 上；上面 /api/ 已覆盖，/_/ 若无 IP 白名单需求可整体反代
```

```bash
sudo ln -s /etc/nginx/sites-available/nexus /etc/nginx/sites-enabled/
sudo nginx -t && sudo systemctl reload nginx
```

## 4. HTTPS（certbot）

```bash
sudo apt install certbot python3-certbot-nginx
sudo certbot --nginx -d sync.example.com
# 自动改写 Nginx 为 443 + 证书自动续期（certbot renew）
```

## 5. 首次数据建立（二选一）

- **服务器为空、本地有历史数据（常见）**：前端 → 设置 → 云端同步 → 填 `https://sync.example.com` + 账号密码 → 「保存并连接」→「全量推送」。历史数据入队上传，随后自动拉取增量。
- **服务器已有数据（如另一台设备先推过）**：新设备只填账号连接即可，首次拉取（游标为 0）会全量拉回做 LWW 合并，几分钟内本地完整重建。

## 8. 已知边界（与计划一致）

- LWW 冲突接受覆盖，不做字段级合并（2.3 定案）
- 统计数据（EXP/连击/奖杯进度）不同步，两端各自从源记录推导
- 附件经 PocketBase 文件存储同步（单文件 ≤ 20MB），本地 Blob 可丢弃重建
- 密码仅存本机 IndexedDB、401 时本机自动重登一次；token 不含密码，不进任何同步载荷

## ⚠️ Schema 升级流程（应用每次新增字段/表时必做）

应用的数据模型演进（如 v4 新增 todoLists 表、todos.listId 字段）时，服务端 collections 必须同步升级，否则 PB 会**静默丢弃**未知字段（不报错）：

1. 本地 `pb_setup/collections.json` 已随代码更新
2. 重新导入：管理后台 → Settings → Import collections（或 API `PUT /api/collections/import`，superuser 鉴权，`deleteMissing: false`）
3. 已推送过的旧记录补字段：前端再执行一次「全量推送」（LWW 会用带新字段的本地版本覆盖服务端）

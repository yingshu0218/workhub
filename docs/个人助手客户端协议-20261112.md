## Endpoint 与会话

Web 的 HTTP 请求使用站点同源相对路径。Tauri 首启要求配置 HTTPS 根地址，拒绝账号、路径、查询参数和片段；开发构建可显式使用 HTTP。初始化、登录/续期/改密、客户端状态、查询、预览/提交/撤回、普通命令、附件与设备授权都经统一 endpoint。切换地址或身份递增连接 epoch，取消在途请求，并在正文解析后再次核验 epoch，不能只检查响应头到达时刻。

`GET /api/workhub/client-state` 需要已登录拥有者身份，返回 `owner / generation / schema:6 / syncProtocol:1`。认证、初始化状态或协议核验失败时不挂载业务界面。已验证会话运行中断网可以读明确标记的已有缓存、编辑草稿；冷启动离线、401/403、认证 5xx 不放行私人缓存。

缓存数据库及草稿/未知请求键均绑定 `[server, owner, generation, schema]`。token 按站点保存。更换会话重挂页面与订阅、清理计时/轮询/业务事件；旧异步响应不能写入新库。旧世代输入通过“设置 → 数据与备份”按同服务器、同账号列出，可导出原请求上下文并核对回执，不自动换世代重放。其他账号和站点的草稿不会混进导出。

这里的 `schema:6` 是客户端缓存协议命名空间。业务 JSON 副本仍为 `schemaVersion:5`，没有改写原业务副本语义；应用包版本仍为 `0.1.0`，未与项目交付编号强行同步。

## 跨表读取

`POST /api/workhub/sync` 需要拥有者会话；Agent 独立凭据不能下载整套镜像。

请求为 `{mode:'snapshot'|'delta', limit:1..200, cursor?}`。响应含 `mode / owner / generation / schema / watermark / changes / nextCursor / complete / readCount`。`changes` 每项为 `{table,id,row}`，附件另含受认证下载所需的文件元数据；永久清理用 `row:null`。`readCount` 是本页返回的业务记录/变更行数，不代表零数据库查询。

- 首启/明确修复使用快照，固定操作水位，按表及 localId 做有界 keyset 分页。期间水位改变返回 `SNAPSHOT_RESTART_REQUIRED`，不能发布混合时刻的数据。
- 增量按 `operation_effects.sequence/ordinal` 读取，固定全窗口水位。当前行可能在后续操作中改变，因此水位前进时返回 `SYNC_RESTART_REQUIRED`，从最后完成游标重取整个窗口，不能把未来行混入旧窗口。
- 游标绑定拥有者、恢复世代、协议/缓存 schema 和位置。恢复返回 `RECOVERY_REVIEW_REQUIRED`。服务端所有读取仍受拥有者与能力校验，游标不是授权秘密。
- 客户端保留阶段计数，缺页/失败不清库、不推进完成游标。完整窗口和游标在同一镜像事务发布；首轮中途退出下次重新取未完成窗口。
- 较高 rev 不被低 rev 覆盖；永久清理登记跨同世代修复快照保留。已经被完成水位覆盖的旧回执不再应用；缺水位的旧格式回执不会覆盖已建立的缓存。晚快照遇本端新回执必须重建，不能先 clear 后丢弃高 rev。
- 空变化且游标未前进时不广播，避免打断编辑。Agent 预览/撤回即使没有业务 effects，也推进操作水位，仍刷新待确认列表和查询缓存。

默认每 30 秒有界轮询；online、pageshow、重新可见和原生 `workhub:resume` 触发补拉。后台隐藏时停止主动轮询，退出移除事件和计时器。Tauri 移动生命周期转发固定 JS 事件。Android 调试 APK、SDK/NDK 构建与当前自动验证的后续证据见 [PROGRESS](PROGRESS.md)和[Android 客户端验收](Android客户端验收-20261112.md)；不改变这里的协议语义。

## 写入、详情与隐私

普通表单仍走 server-first StorageAdapter；事务调用当下捕获会话，排队执行、附件暂存、世代读取、未知请求保存和提交前后均校验。未知结果保留原 requestId/世代/输入；回执恢复共用同一镜像发布器，不另写一套 table.put。

时间线、今天、图谱、联系人与记录详情消费第二版的有界查询。下一页绑定当前查询版本，切换筛选、刷新和卸载后丢弃旧续页；图谱失败/空范围销毁旧节点及标签。来源、正文、关系、历史和 effects 显式继续读取，长正文未读全不能用展示首段覆盖真源。纠错只提交真正改动字段；完整未提交标题/正文和原 expectedRev 独立保存，不静默 rebase。

网页发起的变更先预览再确认。Agent 发起的待确认操作只引导回原发起端确认/撤回，不放宽 clientId 绑定。明确 400 校验拒绝解锁输入，网络未知结果继续核对原请求。事件清理可以显式选择相关范围，共享附件不足范围由服务器拒绝；独立流水与承诺默认保留。

## 附件与备份

`GET /api/workhub/attachments/{业务ID}/file` 需要拥有者登录头，每次校验权限、存在性和软删状态；响应为 `private, no-store` 的下载流。token 不进 URL。标准 PB 受保护文件需要短期文件 token；下载事件的 HTTP 字段在 `requestEvent` 下，仍校验拥有者/能力及删除状态。两条正例都用真实 PB 0.40.2 验证。版本行为依据 [0.40.2 文件 API 源码](https://github.com/pocketbase/pocketbase/blob/v0.40.2/apis/file.go)及该二进制实际生成的类型和运行结果，不能套用最新文档猜测。

设置中的三种导出明确区分：当前缓存/草稿核对副本；同账号旧世代/旧队列核对副本；在线重建后导出的 v5 业务 JSON（含可读取附件）。它们都不是完整恢复备份，不包含整套操作回执、授权凭据、删除登记及恢复元数据。完整恢复继续使用服务端冷备份、文件校验和隔离恢复；恢复先轮换世代并核对清理登记，再开放访问。
